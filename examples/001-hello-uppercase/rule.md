# Rule: hello-uppercase

Given a plain-text input, produce an output containing the same text, uppercased, with no other changes
(whitespace and line breaks preserved exactly).

This is a toy rule local to this example — see `examples/README.md`. A real `SPEC.md` rule would need to
say a lot more (what makes an input this rule applies to, what "plain text" means precisely, encoding),
none of which is worth deciding for a rule that only exists to exercise the example format.
